# 📚 북스터디

## 💁‍♀️ 스터디 소개

- 흥미로운 기술 서적을 읽고, 내용을 정리하며 의견을 공유합니다.
- 함께 읽을 책 목록은 회의를 통해 선정됩니다.

<br/>

## 📖 진행 방식

- 해당 저장소를 클론받아 GitHub 아이디로 브랜치를 생성합니다.
- 회의를 통해 정해진 분량만큼 책을 읽고 개인브랜치에 자유롭게 의견을 기록합니다.
- 매주 월요일 20시 디스코드에 모여 정리한 내용을 공유합니다.
- 각자 정리한 내용을 취합해 메인브랜치에 반영합니다.
    - `메인브랜치` → `{책 이름} 디렉토리` → `{챕터} 파일`


<br/>


## 💬 커밋 컨벤션

- 파일 이름은 다음과 같습니다.
    
    > NN. {책이름}
    > 
    > ex) 01. 전문가를 위한 리액트
- 커밋 메세지 형식은 다음과 같습니다.
    
    > [ {챕터이름} ] : {주제(자유)}
    > 
    > ex) [ 1장 ] : 리액트 이전에는 어땠을까요
