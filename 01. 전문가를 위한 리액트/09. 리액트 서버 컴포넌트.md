### 리액트 서버 컴포넌트란 ?

- 서버에서 실행되는 컴포넌트로 클라이언트 자바스크립트 번들에 포함되지 않음
- 빌드 시점에 실행될 수 있어 정적 콘텐츠를 가져오거나, 데이터 레이어에 접근할 수 있음
- 안전한 서버 환경에서 실행되므로 민감한 정보가 유출되지 않는다.

### 서버 컴포넌트와 서버 렌더링

- 서버컴포넌트는 서버에서만 실행되어 리액트 엘리먼트를 반환하고,
- 그 앨리먼트 트리는 직렬화되어 클라이언트로 전달되고,
- 클라이언트는 받은 데이터를 역질렬화해서 렌더링 트리를 만든다.
- 클라이언트는 동시에 자바스크립트 번들을 병렬로 다운로드 하고,
- 다운로드가 완료되면 렌더링된 화면에 핸들러를 부착해주는데 이 과정을 하이드레이션이라고 한다.
- 그리고 위의 모든 과정이 서버렌더링이다.

### 서버 렌더링에서 참인 명제

- 서버 컴포넌트는 서버에서 실행되며 리액트 엘리먼트를 나타내는 객체를 출력한다.
- 클라이언트 컴포넌트는 서버에서 실행되며 리액트 엘리먼트를 나타내는 객체를 출력한다.
- 서버에는 클라이언트와 서버 컴포넌트의 모든 리액트 엘리먼트를 표현하는 커다란 객체가 있다.
- 이 객체는 문자열로 변환되어 클라이언트로 전송된다.
- 이 시점부터 서버 컴포넌트는 클라이언트에서 실행되지 않는다.
- 이 시점부터 클라이언트 컴포넌트는 클라이언트만 실행된다.

### 서버 컴포넌트 규칙

- 서버 컴포넌트는 모든 프롭을 직렬화 할 수 있어야 한다. → 즉 함수를 프롭으로 전달할 수 없다.
- 서버 환경은 DOM이나 window 객체가 없으므로 부작용이 있는 훅은 사용하면 안된다. < 뭐어쩌란거 ?
- 서버 컴포넌트와 클라이언트 컴포넌트의 상태는 동일하지 않다.< 뭐어쩌란거 ? 2
- 클라이언트 컴포넌트에서는 서버 컴포넌트를 가져올 수 없다.

### 서버 액션

- 함수 호출을 서버에서 직접 실행하는 React의 기능
- 클라이언트에서 호출했지만, 함수 로직은 서버에서 실행된다.
- API라우트 없이 서버와 직접 통신 가능하다.

2. **클라이언트 컴포넌트가 서버 컴포넌트를 가져올 수 있나요? 그렇게 답변한 이유가 무엇인가요?**
