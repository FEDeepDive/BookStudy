## 📌JSX 개념

JSX란 `자바스크립트 확장 구문(Javascript Syntax eXtension)`으로, HTML과 비슷한 마크업을 자바스크립트 파일 안에서 작성할 수 있게 해준다.

⇒ JSX를 사용하면 하나의 JS 파일(=컴포넌트) 안에 렌더링 로직과 마크업을 함께 둘 수 있음

⇒ JSX를 실행하려면 컴퓨터가 JSX를 이해할 수 있도록 하는 전용 도구가 필요함

## 📌JSX 실행 과정

```
- 컴파일: 상위 수준 언어로 작성된 코드를 하위 수준 언어로 변환
- 트랜스파일: A 언어로 작성된 코드를 추상화 수준이 비슷한 B 언어 코드로 변환
- 빌드: 컴파일/트랜스파일, 모듈 번들링, 최적화, 압축 등 전체적인 변환 과정
```

JSX를 동작시키려면 1️⃣JSX 엔진을 만들거나 2️⃣JSX를 JS로 변환하여 JS 엔진으로 실행

2️⃣가 압도적으로 쉬움

→ JSX 전용 구문 분석기(Parser), 렉서(lexer)가 필요

→ JSX를 파싱 및 렉싱해 Syntax Tree를 생성 & JS로 변환

→ 기존 JS 엔진으로 변환한 JS 파일을 실행

## 📌JSX 프래그마(Pragma)

<aside>

`프래그마(Pragma)`란 언어 자체에 내포된 것 이상의 추가 정보를 컴파일러에 제공할 때 사용하는 컴파일러 지시어이다. 예시로 JS 프래그마로는 `use strict`가 있다.

</aside>

JSX 프래그마는 모두 `<`로 시작한다. JSX 구문 분석기가 `<`를 만나면 `React.createElement()` 또는 `_jsxs()` 함수를 호출한다(다른 함수로도 설정 가능). 즉 JSX 프래그마는 **여러 번 반복 호출되는 함수에 대한 문법적 설탕**(혹은 별칭)이라고 할 수 있다.

## 📌복습하기

- ❓**JSX란 무엇이며, 장단점은 무엇인가요?**
    - JSX 개념
        - 자바스크립트 확장 구문 (Javascript Syntax eXtension)
        - 자바스크립트 코드 내에서 HTML과 유사한 마크업 코드 작성 O
    - 장점
        - 엘리먼트 트리 내부에서 표현식 사용 가능 ⇒ 유연함
        - 타입 안정성 향상이 가능 (ex. TypeScript, JSDoc, [propTypes](https://ko.legacy.reactjs.org/docs/typechecking-with-proptypes.html))
    - 단점
        - 관심사 분리 X (표현-논리 혼합)
        - JSX를 JS로 변환하기 위한 전용 도구가 필요
- ❓**JSX와 HTML의 차이점은 무엇인가요?**
    
    
    |  | JSX | HTML |
    | --- | --- | --- |
    | 개념 | JS의 확장 구문 | 마크업 언어 |
    | 인라인 표현식 | O | X |
    | 속성 네이밍 | 카멜 케이스 (ex. onClick) | 소문자만 사용 (ex. onclick, data-*) |
    | 엘리먼트 네이밍 | 파스칼 케이스 (ex. Div) | 소문자만 사용 (ex. div) |
    | 💬태그 규칙 | 단일 요소로 반환 & 모든 태그 닫기 | - |
- ❓**텍스트 문자열은 어떻게 기계어가 되나요?**
    
    `컴파일` 과정을 통해 문자열 뿐인 소스 코드를 컴퓨터가 이해할 수 있는 기계어로 변환한다.
    
    컴파일 과정은 크게 1️⃣`토큰화`, 2️⃣`구문 분석(Parsing)`, 3️⃣`코드 생성`으로 이루어진다.
    
    1️⃣먼저 문자열을 의미가 있는 ‘토큰’으로 분해한다. 정규 표현식을 사용해 문자열을 규칙에 따라 토큰으로 분해할 수 있다.
    
    2️⃣이후 토큰을 가지고 구문 트리(Syntax Tree)를 생성한다. 구문 트리는 코드의 구조를 나타내는 자료 구조이다.
    
    3️⃣추상 구문 트리(AST)를 컴퓨터가 이해할 수 있는 기계어로 변환하고 실행한다.
    
- ❓**JSX 표현식이란 무엇이며 어떤 좋은 점이 있나요?**
    - 자바스크립트 표현식을 중괄호로 감싸서 엘리먼트 트리 안에서 사용 가능
    - ⇒ 삼항 연산자로 조건 검사, JS 메서드 사용 등 **생산성 ↑, 유연함 ↑**
