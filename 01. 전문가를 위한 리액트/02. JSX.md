js 호환성 부족

```
￭ JSX에서{} 중괄호는 표현식 슬롯을 만든다
￭ 표현식 슬롯에서 값을 생성하지 않는 문은 사용할 수 없다
￭ 즉, JSX{} 중괄호 안에선 값을 생성하는 표현식만 사용할 수 있다
￭ 따라서if, swtich와 같은 문은 사용할 수 없다.
```

   - `{}` 안에서 JS 표현식 사용 가능, 문자열 보간보다는 더 안전하고 문법 체크가 엄격.
   - JSX 내부에서는 항상 값을 리턴해야 함으로 if문이나 switch같은 블록은 지원하지 않음

3. **텍스트 문자열을 어떻게 기계어가 되나요?**
   1. **토큰화 (Tokenization, Lexical Analysis)** → 코드를 작은 토큰으로 분해
   2. **구문 분석 (Parsing)** → 토큰을 AST(추상 구문 트리)로 변환
   3. **(옵션) 트랜스파일링 (Transpiling)** → Babel, TypeScript 변환 과정
   4. **바이트코드 생성** → AST를 바이트코드로 변환
   5. **인터프리터 & JIT 컴파일러 실행** → JIT이 핫 코드를 기계어로 변환하여 최적화

> **얼마전에 본 강의자료**

> JSX(React 엘리먼트) 종류:
>
> 1. **문자열 / 숫자** → 그대로 HTML 텍스트
> 2. **배열** → 순회하며 각각 렌더
> 3. **태그(String type)** → `<div>...</div>`처럼 HTML 태그로 변환
>
>    - renderJSXToHTML 1버전
>      ```jsx
>      function renderJSXToHTML(jsx) {
>        if (typeof jsx === "string" || typeof jsx === "number") {
>          // This is a string. Escape it and put it into HTML directly.
>          return escapeHtml(jsx);
>        } else if (jsx == null || typeof jsx === "boolean") {
>          // This is an empty node. Don't emit anything in HTML for it.
>          return "";
>        } else if (Array.isArray(jsx)) {
>          // This is an array of nodes. Render each into HTML and concatenate.
>          return jsx.map((child) => renderJSXToHTML(child)).join("");
>        } else if (typeof jsx === "object") {
>          // Check if this object is a React JSX element (e.g. <div />).
>          if (jsx.$$typeof === Symbol.for("react.element")) {
>            // Turn it into an an HTML tag.
>            let html = "<" + jsx.type;
>            for (const propName in jsx.props) {
>              if (
>                jsx.props.hasOwnProperty(propName) &&
>                propName !== "children"
>              ) {
>                html += " ";
>                html += propName;
>                html += "=";
>                html += escapeHtml(jsx.props[propName]);
>              }
>            }
>            html += ">";
>            html += renderJSXToHTML(jsx.props.children);
>            html += "</" + jsx.type + ">";
>            return html;
>          } else throw new Error("Cannot render an object.");
>        } else throw new Error("Not implemented.");
>      }
>      ```
>

>    컴포넌트가 함수여서 생기는 문제 (function이란 태그가 html에서 부자연스러움)
>
>    ```
>    <!-- This doesn't look like valid at HTML at all... -->
>    <function BlogPostPage({postContent,author}) {...}>

>
>    - renderJSXToHTML 2버전
>      이 코드를 추가함
>      ```jsx
>      if (jsx.$$typeof === Symbol.for("react.element")) {
>        if (typeof jsx.type === "string") {
>          // Is this a tag like <div>?
>          // Existing code that handles HTML tags (like <p>).
>          let html = "<" + jsx.type;
>          // ...
>          html += "</" + jsx.type + ">";
>          return html;
>        } else if (typeof jsx.type === "function") {
>          // Is it a component like <BlogPostPage>?
>          // Call the component with its props, and turn its returned JSX into HTML.
>          const Component = jsx.type;
>          const props = jsx.props;
>          const returnedJsx = Component(props);
>          return renderJSXToHTML(returnedJsx);
>        } else throw new Error("Not implemented.");
>      }
>      ```
>      ```jsx
>      function renderJSXToHTML(jsx) {
>        if (typeof jsx === "string" || typeof jsx === "number") {
>          return escapeHtml(jsx);
>        } else if (jsx == null || typeof jsx === "boolean") {
>          return "";
>        } else if (Array.isArray(jsx)) {
>          return jsx.map((child) => renderJSXToHTML(child)).join("");
>        } else if (
>          typeof jsx === "object" &&
>          jsx.$$typeof === Symbol.for("react.element")
>        ) {
>          // Element(React 엘리먼트)
>          if (typeof jsx.type === "string") {
>            // html 태그(<div>, <span> 등)
>            let html = `<${jsx.type}`;
>            const props = jsx.props || {};
>            for (const propName in props) {
>              if (propName !== "children") {
>                html += ` ${propName}="${escapeHtml(props[propName])}"`;
>              }
>            }
>            html += ">";
>            html += renderJSXToHTML(props.children);
>            html += `</${jsx.type}>`;
>            return html;
>          } else if (typeof jsx.type === "function") {
>            // 컴포넌트
>            const Component = jsx.type;
>            const props = jsx.props || {};
>            const renderedJSX = Component(props);
>            return renderJSXToHTML(renderedJSX);
>          }
>          // 확장 가능...
>        }
>        // ...
>      }
>      ```
>    - `renderJSXToHTML(<BlogPostPage postContent="..." author="..." />)` 호출 시 → `<BlogPostPage>` 컴포넌트 내부 JSX가 HTML이 됨
