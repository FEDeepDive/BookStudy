## 아이템 12. 함수 표현식에 타입 적용하기
저는 대부분의 경우 리액트 컴포넌트를 함수 표현식으로 작성합니다! 위에서 잠깐 이야기했던 `type MyProps = ComponentProps<typeof Component>` 같은 타입을 사용하면 `type MyComponent = (props: MyProps) => JSX.Element` 같은 식으로 컴포넌트 타입을 지정해서 `const Comp: MyComponent = (props) => <>{...}</>` 뭐 이런 식으로 사용할 수 있을텐데... 사실 이렇게까지 극단적으로 줄이지는 않고 props 타입 정도만 따로 빼서 선언해두고 사용하는 경우가 많네요
